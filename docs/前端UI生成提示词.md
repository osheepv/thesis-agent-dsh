# 前端 UI 生成提示词（概念图 / 设计稿用）

> 用途：拿着这份需求让 AI（Figma First Draft / Cursor / 即梦 等）生成**产品 UI 概念图/线框图**，
> 生成后发回来，我照着图纸实现前端代码。
> 技术栈：React + Vite + antd 5 + ProComponents + TipTap（编辑器）+ Cytoscape.js（图谱）。
> **产品定位：桌面 AI 应用**（后续用 Tauri 打包成 desktop），界面风格参照主流 AI 桌面客户端
> （Cherry Studio / Obsidian / Notion / Cursor）——**不是企业后台仪表盘**。

---

## 一、给 AI 的提示词（直接复制）

### 风格基准（每段提示词开头都带上）

> **设计风格参照主流 AI 桌面客户端**（Cherry Studio / Obsidian / Notion / Cursor）：
> 三栏或双栏布局、左侧窄导航（图标+文字）、主内容区居中、右侧信息/预览面板、
> 顶部工具条轻量、卡片圆角 8px、浅灰背景+白色卡片+深蓝主色、现代简洁无仪表盘感。
> 中文界面，桌面 1440px 宽屏，字重层级清晰，避免"企业后台报表"样式。

### 页面 1：任务列表（主界面，类 Obsidian/Cherry Studio 首页）

```
Web Dashboard「学位论文写作 Agent」首页，参照 Cherry Studio / Obsidian 桌面客户端风格：
左侧窄导航栏（宽 220px：Logo + 任务列表/知识库/检索/设置 4 个入口，图标+文字，选中态深蓝），
顶部轻量工具条（当前页面标题 + 右侧用户头像 + 新建任务 Primary Button），
主内容区：任务卡片网格（每张卡片：题目/学位标签[本科|硕士|博士彩色 Tag]/进度条/
当前环节/更新时间，卡片白色圆角 8px 阴影浅，悬停抬升），
底部状态栏（任务总数/进行中/知识库文献数 3 个小统计）。
严格使用 Ant Design 5.x 色值与间距，无仪表盘报表卡片堆砌。
```

### 页面 2：论文流程详情（类 Notion/Cursor 的工作区）

```
Web Dashboard「论文流程详情」，参照 Notion / Cursor 桌面工作区风格：
顶部：任务标题（大字）+ 学位标签 + 状态徽章 + 操作按钮组（执行当前环节/重新生成/
导出 docx，轻量按钮），
主内容区左侧：当前环节产物预览（题目候选列表/大纲树/章节正文/参考文献，白卡片），
右栏（宽 320px）：10 环节步骤条竖向（选题→开题评审→文献调研→综述评审→大纲→撰写→
润色→引用校验→排版→定稿，每环一行业务图标+状态色[✓通过绿/进行中蓝/未开始灰/回退橙]，
点击切换查看该环产物），
底部：回退历史时间线（轻量文字行）。
风格参照 Cursor 的顶栏+左侧内容+右侧面板，现代简洁。
```

### 页面 3：文献检索（类桌面 AI 的搜索页）

```
Web Dashboard「文献检索」，参照 Cherry Studio 的搜索/聊天输入区风格：
顶部搜索输入框（大、圆角、左侧放大镜图标）+ 右侧检索范围下拉（全部/英文/中文），
输入框下方数据源勾选行（Crossref/OpenAlex/Semantic Scholar 已启用 + 知网/NCPSSD/
ChinaXiv 引导层，勾选框+小标签），
主区：检索结果列表（行式卡片：标题/作者/年份/期刊/可靠度徽章[verified绿|matched蓝|
discovery灰|uncertain橙]/行尾操作：复制 GB/T 7714 图标 + 跳转下载按钮），
右侧抽屉/侧栏：已选文献池（数量+导出参考文献按钮），
底部：标准检索通道登记平台表格（精简）。
```

### 页面 4：知识库（双链笔记，类 Obsidian）

```
Web Dashboard「知识库」，**直接参照 Obsidian 桌面客户端三栏布局**：
左栏（宽 240px）：笔记/文献目录树（按会话分组，文件夹图标+条目，激活高亮），
中栏：Markdown 笔记编辑器（TipTap：标题层级/段落/代码块，输入 [[ 弹出笔记搜索
自动补全下拉，双链显示为浅蓝链接样式），
右栏（宽 300px）：反向链接面板（"被 N 篇笔记引用"列表，条目点击跳转）+ 文献详情
（题录字段 + GB/T 7714 复制按钮），
底部：保存状态 + 字数。
风格像素级参照 Obsidian：三栏分隔线浅灰、笔记内容区白、侧栏浅灰背景。
```

### 页面 5：知识图谱（类 Obsidian Graph View）

```
Web Dashboard「知识图谱」，**直接参照 Obsidian 的 Graph View**：
全画布力导向关系图（背景深灰/黑色，节点发光：文献=蓝色方块/笔记=绿色圆点，
大小按被引用数，边=[[引用]]半透明线，悬空链接虚线），
左上浮动工具栏（深度滑块/节点大小/边显示开关/缩放/聚焦当前笔记，半透明背景圆角胶囊），
节点点击：弹出预览浮动卡片（标题+摘要+打开编辑按钮，白底圆角阴影）。
保持 Obsidian Graph 的"深色画布+发光节点+柔和力布局"视觉。
```

### 页面 6：设置（类桌面 APP 设置页）

```
Web Dashboard「设置」，参照 Obsidian / Cherry Studio 设置面板（左列表右表单）：
左栏（宽 200px）：设置分类列表（模型/检索/知识库/模板/关于），
右栏表单：DeepSeek API Key（输入框+显示隐藏）| 秘塔检索 Key（可选 BYOK）|
检索默认范围下拉 | 文献目标数量 | docx 学校模板上传（拖拽区域），
底部说明文本（灰色小字）："中文平台为引导层，用户自行下载文献到会话知识库文件夹"。
风格桌面 APP 设置页，简洁。
```

| 任务卡片网格 | 题目 + 学位标签（本科/硕士/博士）+ 进度条 + 当前环节 + 更新时间 |
| 新建任务按钮 | 模态框：题目 / 学位 / 学科域 / 检索范围（english/chinese/all） |

### 页面2 论文流程详情（10 环节）
| 部件 | 说明 |
|---|---|
| **10 步步骤条** | Step1 选题→Step10 定稿；状态色（✓通过/进行中/未开始/回退） |
| 当前环节产物面板 | 题目候选 / 大纲 / 章节正文 / 参考文献（GB/T 7714 列表） |
| 操作按钮 | 执行当前环节 / 重新生成 / 导出 docx / 运行全部（演示用） |

### 页面3 文献调研（标准检索通道）
| 部件 | 说明 |
|---|---|
| 检索框 + scope 下拉 | 全部 / 英文 / 中文 |

| 结果列表行 | 标题 / 作者 / 年份 / 期刊 / **可靠度徽章**（verified 绿 / matched 蓝 / discovery 灰 / uncertain 橙色"待人工"） |

| 底部说明 | 标准检索通道登记平台表（平台名/语言/是否 API/合规） |

## 三、交互细节（概念图需体现）

1. **新建任务**：表单必填（题目/学位/学科域），检索范围默认"全部"
2. **执行环节**：点击"执行当前环节" → 按钮 loading → 完成后步骤条更新；评审未通过 → 橙色警告+回退按钮
3. **检索**：勾选源 → 点搜索 → 结果列表按可靠度着色；"加入文献池"累积到右侧
4. **笔记编辑**：`[[` 自动弹出笔记搜索框（输入过滤，回车创建新笔记）；双链在右侧显示反链
5. **图谱**：力导向自动布局；节点拖拽/缩放/居中；点击弹出预览卡
6. **所有页**：右上角"文档/API 参考"链接（Swagger）、"演示模式"按钮（跑全流程 demo）
