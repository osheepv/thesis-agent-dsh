# 前端 UI 生成提示词（概念图 / 设计稿用）

> 用途：拿着这份需求让 AI（Figma First Draft / Cursor / 即梦 等）生成**产品 UI 概念图/线框图**，
> 生成后发回来，我照着图纸实现前端代码。
> 技术栈：React + Vite + antd 5 + ProComponents + TipTap（编辑器）+ Cytoscape.js（图谱）。
> **产品定位：AI Agent 桌面客户端**（后续 Tauri 打包成 desktop），
> **界面风格直接参照 Codex / Claude Code / DeepSeek Harness (dsh) 的桌面版**。
>
> **核心数据模型（重要，概念图必须体现）**：
> **对话（论文任务）= 会话 = 知识库，1:1 强绑定**。新建对话即新建该对话专属知识库；
> 对话流程（10 环检索/文献池/笔记/图谱）完全依托本对话知识库；删除对话时知识库一并删除。
> 因此 UI 上：知识库**不是独立全局页面**，而是**对话工作区的内置面板**（该对话的文献/笔记/图谱页签），
> 对话在哪，它的知识库就在哪。

## 一、给 AI 的提示词（直接复制）

### 风格基准（每段提示词开头都带上）

> **设计风格：完整复刻 Codex / Claude Code / DeepSeek Harness 桌面客户端的视觉语言**——
> 顶部极简工具栏（Logo + 当前对话名），左侧窄栏**对话/任务列表**（小图标+条目，选中态高亮），
> 主区是**对话工作区**：对话流（用户消息 + AI 消息，AI 消息含 Markdown 渲染、卡片、状态徽章）
> + **右侧该对话专属知识库面板**（文献池/笔记/图谱页签，跟对话 1:1，非独立全局页面），
> 底部大输入框（对话式发送 + 上下文徽章）。
> 细节：深色 + 浅色双主题（默认深色），Monospace 字体点缀（路径/JSON/代码），
> 卡片圆角 8px、浅灰分隔线、高信息密度，现代极简，无仪表盘感。

```

    系统自动验收通过 + 用户点击确认，双闸门才推进（按钮上方小字

    评审未通过（环2/4）时：橙色警告卡片 + "重新生成/回退修改"按钮；
```

### 说明（补充，概念图不单独画）

- **双重验证（每环闸门）**：每环完成后先系统自动验收（accept），
  再展示"确认进入下一环"按钮；**用户点击确认才推进**（对应后端 M1 FSM
  advance accept + hitl 确认），顶部进度条实时同步。评审未通过（环2/4/8）
  不走闸门，直接显示警告 + 提供回退/重新生成。
- 知识库不是独立入口：左侧栏不设"知识库"全局页签；每个对话的文献/笔记/图谱都在
  该对话工作区右侧面板内（对应代码：storage/kb/{session_id}/，会话删除即目录移除）。
- 检索功能内嵌在对话流（用户指令"检索…"→ AI 回复里展示结果卡片，中文平台去重引导跳转），
  不需独立检索页。
- 每环确认后阶段进度条自动点亮；全局"全部运行"按钮不默认展示（保留在设置内），
  主流程强调用户逐环确认。
