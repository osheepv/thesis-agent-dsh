# Deep Thesis — UI 设计（桌面工作台风格）

> 来源：基于 cc-haha(MIT) 提取的官方 Claude Code 桌面端设计规范 + 我们产品的对话/进度条/知识库模型。
> 配色 = Claude 官方配色（品牌橙 `rgb(215,119,87)`，浅色暖白 / 深色中性灰双主题）。

---

## 一、整体设计语言

- **风格**：现代简约、暖色调，类 Notion/Linear（Claude Code 桌面端原味）
- **主题**：Light（默认，暖白）+ Dark（中性灰）双主题
- **圆角**：大圆角——卡片 12px、输入框 16px、按钮 8px、模态 16px
- **阴影**：微妙，仅浮层/下拉（`0 4px 12px rgba(0,0,0,0.1)`）
- **图标**：线条图标，1.5px 线宽，圆角端点
- **字体**：`-apple-system, SF Pro Text, Segoe UI, Inter`（正文）
  + mono `SF Mono, JetBrains Mono, Fira Code`（路径/JSON/代码）

## 六、我们产品的定制（在 Claude 骨架上的业务层）

### 6.1 对话 = 会话 = 知识库（1:1）
- 新建对话 → 左侧列表新增项 + 该对话专属知识库（`storage/kb/{session}/`）
- 右侧（可折叠面板 280px）：**文献池 / 笔记 / 图谱** 三个页签，跟对话同生同死
- 删除对话（✕）→ 确认"将一并删除该对话的知识库"

### 6.2 对话级阶段进度条（每对话独立）
- 位置：侧栏与主区之间顶部（或对话流顶端，随选中对话切换）
- 10 节点：选题→开题→文献→综述→大纲→撰写→润色→引用→排版→定稿
- 状态：已完成 = 成功绿 ✓ / 当前 = 品牌橙高亮 + 脉冲 + "等待确认"灯 /
  未开始 = 灰 / 回退 = 警告琥珀

### 6.3 每环人工确认闸门（双重验证）
- 每环完成：系统自动验收通过（绿 ✓）→ AI 消息末尾出现
  **「确认进入下一环」主按钮**（深灰底白字，圆角 8px）
- 按钮上方小字："已完成自动校验，待您确认后进入下一环"
- 评审未通过（环2/4/8）：**不走闸门** → 警告卡片（warning 琥珀）+ "重新生成/回退修改"
- 10 环完成：定稿汇总卡片 + 「确认定稿」（最后闸门）

### 6.4 文献/知识库交互
- 检索结果卡片内嵌对话流：可靠度徽章（`verified` 成功绿 / `matched` 蓝 /
  `discovery` 灰 / `uncertain` 琥珀"待人工"）
- 中文平台跳转下载：蜜橙色链接按钮 → 浏览器打开 → 用户下载存知识库
- 文献池页签：列表 + 复制 GB/T 7714（品牌橙图标）
- 笔记页签：TipTap 编辑器 + `[[双链]]` 弹出补全（permission 蓝紫链接样式）
- 图谱页签：力导向图（深色画布，节点发光，Claude 橙/绿圆点）
