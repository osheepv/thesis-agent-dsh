## 一、接入原则

1. 不整包安装 Nature Skills，不启用 SessionStart 自动更新。
2. 不把第三方 Markdown 直接作为生产系统提示词。
3. 不新建与 `PROJECT_MEMORY`、`EvidenceLedger`、`ARGUMENT_MAP`、`OUTLINE` 平行的仓储。
4. 事实只能从当前任务已批准、可定位的 Evidence 或用户核验 Result 投影；自由文本不能自报“已证实”。
5. 第三方规则必须转成服务端结构校验、版本依赖、Gate 和确定性测试。
6. 期刊政策与合规规则执行时在线核对官方来源，本地快照只作路由提示。

## 四、M1 验收标准

- 旧 payload 无新字段仍通过并获得安全默认值。
- 新字段去重、长度、未知字段与数值边界由 Pydantic fail closed。
- 待审批/驳回/过期记忆不得进入 Agent 上下文。
- 缺关键证据优先于“目标已完成”，停止报告包含稳定原因码与唯一下一步。
- UI 提交、恢复和版本摘要完整保留范围边界、禁写主张、未决主张与停止预算。
- 全量 pytest、前端语法、真实浏览器和 Wheel 构建通过后才允许提交。
