## 3. 轮子选型总表（调研结论）

> 逐项经过 2026-08 GitHub 检索核实。✅=直接采用　⚠️=借鉴/半自研　❌=否决　🚫=禁用（合规红线）

### 3.1 LLM 底座

| 需求 | 选型 | 结论 |
|---|---|---|
| LLM 生成（环1/5/6/7 等） | **openai SDK 直调 `api.deepseek.com`**：`deepseek-v4-flash`（$0.14/$0.28，1M 上下文；**`deepseek-chat` 2026-07-24 已退役勿用**）。~150 行薄封装：base_url + 重试 + 超时 + `response_format=json_object` 结构化输出 + Pydantic 校验 | ✅ 弃 DSH |
| ~~DeepSeek-Harness (DSH)~~ | [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)（2026-08-13 开源，16.7w star）— v0.1 开发预览期、不接受 PR、**官方 Python SDK 不支持 Windows**、定位是完整 Agent 运行时（非提示词编排库） | ❌ 否决 |
| ~~LangChain / LlamaIndex / Dify~~ | 10 环节是顺序 pipeline 非自治 agent loop；重框架只增开销（LangChain 实测单次多 ~10ms、token 多 ~40%）；Dify 自托管 14 个服务不兼容 FastAPI 架构 | ❌ 否决 |

### 3.2 文献检索 / 引文反查 / 全文获取

| 需求 | 选型 | 结论 |
|---|---|---|
| 引文反查/文献检索元数据 | **Crossref**（免费无 key，DOI 权威，生产必加 mailto 进 polite pool）→ **OpenAlex**（免费 key，$1/天预算单用户绰绰有余）→ **Semantic Scholar**（补语义/引用数） | ✅ 主链路 |
| 文献检索客户端 | `semanticscholar`（[danielnsilva/semanticscholar](https://github.com/danielnsilva/semanticscholar) 官方 SDK，typed/批量/分页）替换手写；`arxiv.py`（PyPI `arxiv`，预印本） | ✅ 低成本替换 |
| 全文获取（合法） | **Unpaywall API**（email 即 key，`best_oa_location.url_for_pdf`，DOI→合法 OA PDF 标准答案）→ Europe PMC（生医全文 PDF/XML）→ arXiv | ✅ 必加 |
| 中文文献（社科） | **NCPSSD 国家哲学社会科学文献中心**（ncpssd.cn，免费注册直下 2500w+ 条，国内最大公益社科 OA 平台） | ✅ 合法主通道 |
| 中文文献（理工预印本） | **ChinaXiv**（chinaxiv.org，中科院，OAI-PMH 2.0 标准接口，CC BY 3.0） | ✅ 合法 |
| 中文引文校验 | 免费 API 对中文覆盖差（OpenAlex 仅 37% 期刊/24% 文章/92% 语言标错/DOI 仅 27%）→ 中文条目**降级为"题录字段核对"并标记"待人工/订阅复核"**，绝不冒充校验通过 | ✅ 诚实兜底 |
| 引文校验架构 | 照抄 [markrussinovich/refchecker](https://github.com/markrussinovich/refchecker)（OpenAlex referenced_works + S2 references + Crossref 数组**多源交叉，≥2 源命中才判通过**；强制不用 LLM 猜测） | ⚠️ 照抄架构 |
| 文献筛选（环3/4） | 借鉴 [ASReview](https://github.com/asreview/asreview)（系统综述主动学习筛选，Nature Mach Intell 背书，导入 RIS/CSV）工作流 | ⚠️ 借鉴 |
| ~~知网/万方爬虫~~ | aFlyBird0/CnkiSpider 等**已全线停更失效**（知网 2023 起 Cookie/IP 强绑定+登录态；万方 2024 下线 HTTP 接口改 Web Component+Shadow DOM）；触法风险 | ❌ 否决 |
| ~~Google Scholar 爬虫~~ | scholarly 等违反 GS ToS，CAPTCHA/封锁频发，与学术诚信红线项目冲突 | ❌ 否决 |
| ~~Sci-Hub 类~~ | scihub.py / SciHubEVA / PyPaperBot / doi2pdf 等 | 🚫 禁用（黑名单，在项目约束中显式写出） |

### 3.3 引用格式 / docx 工程

| 需求 | 选型 | 结论 |
|---|---|---|
| GB/T 7714-2015 格式化 | **pybtex** + [DeepPSP/bib_lookup](https://github.com/DeepPSP/bib_lookup)（v0.1.4 内置 `style="gbt7714"`，纯 Python 无 LaTeX，支持 [J/OL]、作者截断） | ✅ 直接用 |
| docx 生成 | **维持 docxtpl + python-docx + openxml-audit**——生态内唯一"把用户 Word 模板本身当渲染引擎"的方案（已论证：Pandoc 双通道/LaTeX/Typst 均否决，见 §4 决策记录） | ✅ 维持+加强 |
| docx 版式检查（环9 规则库） | 自研规则库 + 借鉴三件套架构：`thesis-format-zh`（模板→rules.json→逐段 diff 报告）、`paper_format_agent`（**内容指纹守卫 fail-closed**：格式化前后正文 hash 比对，改内容即中止）、`thesis-docx`（OOXML 底层审计 styleId/firstLineChars/titlePg/REF 域）；规则素材对照 thuthesis/BIThesis 文档中的各校规范条文清单 | ⚠️ 半借架构 |
| 渲染后视觉复检 | docx→PDF（LibreOffice）→逐页检查跨页断表/标题孤行（学 word_chat 验证层） | ⚠️ 建议加 |
| 公式通道 | LaTeX→MathML→Word 原生公式（学 [docx-skill-4-cn-paper](https://github.com/...)），替换公式转图片 | ⚠️ 建议加 |
| 分章渲染合并 | docxcompose（保留页眉页脚/自定义样式） | ⚠️ 可选 |
| ~~Pandoc 双通道~~ | 标题编号无法继承（Pandoc 自造 numbering.xml，issue #1305 未实现）、镜像页边距丢失（#8946）、首段缩进 bug（#9671）——兜底通道会自己过不了合规检查 | ❌ 否决（降级为内容导入工具） |
| ~~LaTeX 学校模板~~ | thuthesis 等只覆盖 60~100 所名校（中国两三千所高校无 LaTeX 模板）、只出 PDF（高校普遍要求 docx）、无法消费用户 Word 模板 | ❌ 否决 |
| ~~Typst~~ | 官方明确不做 docx 导出（#2561 原话），不在路线图；第三方转 docx 全是凑合 | ❌ 否决（可低优先级做 PDF 预览） |

## 4. 关键决策记录

| # | 决策 | 依据 |
|---|---|---|
| D1 | **弃用 DeepSeek-Harness，改直调 DeepSeek API** | DSH 2026-08-13 才开源、v0.1 预览期、官方 Python SDK 不支持 Windows（本项目 Win 环境直接不可用）；10 环节是顺序 pipeline，深框架是负收益；verdict：openai SDK + ~150 行薄封装 |
| D2 | **文献源 = 免费 API + 人工兜底** | 万方 2024 下线 HTTP 接口、知网无开放 API、爬虫全线失效；Crossref/OpenAlex/S2 免费覆盖英文；中文（尤其人文社科）覆盖差→**如实标记"待人工/订阅复核"**，不冒充校验通过 |
| D3 | **查重 out-of-scope** | 设计 O1；付费第三方未确认；引用格式/一致性校验先做（D4/D5） |
| D4 | **docxtpl 维持 + 校验层加强** | 调研证实：GitHub "更专业的格式工具"（LaTeX 模板/Pandoc/Typst）全部绑定单一格式规范，与"用户上传任意学校 Word 模板"架构根本冲突；docxtpl 是唯一"吃模板"方案。**真正的差距在校验层**：环9 规则库 + 内容指纹守护 + 渲染后复检，且该组合在开源生态是空白（差异化机会） |
| D5 | **GB/T 7714 用 pybtex + bib_lookup** | 纯 Python、内置国标样式、无需 LaTeX 环境；citeproc-py 路线仅 60% 通过率弃用 |
| D6 | **文献爬取合规红线** | 知网/万方爬虫全失效；合法通道 = NCPSSD + ChinaXiv + Unpaywall + Europe PMC + 机构订阅（国图读者卡/校园网 + Zotero，做成用户引导不走代码管线）；**Sci-Hub 类进黑名单，项目文档显式禁入**（学术诚信红线是项目卖点，不是风险点） |
| D7 | **知识库自研简单版** | 双链本质 = 笔记表 + 链接表 + 反向查询；AGPL 笔记全家桶（SiYuan/Trilium）不集成，AFFiNE 后端是 Enterprise 许可；PG tsvector 足够，不上向量库（设计原判正确） |

## 6. 项目差异化定位（调研副产物）

开源生态中**不存在**同时解决"任意学校 Word 模板上传 + 自动解析 + docx 输出 + 合规校验"的项目：
- LaTeX/Typst 模板生态：按校定制、只出 PDF（数量天花板 ~100 所）；
- Pandoc 工作流封装（pandoc_docx_template 等）：通用中文学术排版，不针对学校模板；
- thesis-format-zh / paper-format-agent：只有"检查"没有"生成"，且为个人项目；
- 模板市场/索引：Word 学校模板生态为空白。

本项目"用户上传学校模板 → M5 解析 → docxtpl 渲染 → 三重校验 + 规则库合规检查"是该空白的第一套完整组合，值得写进仓库定位。
