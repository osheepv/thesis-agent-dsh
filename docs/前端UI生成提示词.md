# 前端 UI 生成提示词（概念图 / 设计稿用）

> 用途：拿着这份需求让 AI（如 Cursor/Claude/即梦/即时设计 等）生成**产品 UI 概念图/线框图**，
> 生成后发回来，我照着图纸实现前端代码。
> 技术栈：React + Vite + antd 5 + ProComponents + TipTap（编辑器）+ Cytoscape.js（图谱）。

## 一、给 AI 的提示词（直接复制）

```
你是资深 UI/UX 设计师。请为"学位论文全流程写作 Agent 工作台"设计一套 Web 管理后台界面，
风格：现代、清爽、学术感（白底 + 深蓝主色 + 浅灰背景），中文界面，适配 1440px 宽屏。

产品一句话：用户创建论文任务，系统按 10 个环节自动生成/辅助（选题→开题评审→文献调研→
综述评审→大纲→撰写→润色→引用校验→排版→定稿），用户可查看进度、查看文献池、
写双链笔记（Obsidian 式）、看知识图谱。

请设计以下 6 个页面的**线框图/概念图**（每个页面给布局结构、组件位置、交互说明）：

【页面1 任务列表（首页/工作台）】
- 顶部导航栏：Logo + "任务列表" / "知识库" / "检索" / "设置"（Tab）
- 左侧统计卡片：总任务数、进行中、已完成、文献库总篇数
- 中间列表：任务卡片网格（每个卡片：题目/学位标签/进度百分比/当前环节/更新时间）
- 右上：新建任务按钮（模态框：题目+学位+学科域+检索范围）

【页面2 论文流程详情（10 环节进度）】
- 顶部：任务标题 + 学位标签 + 状态
- 中部：10 个环节的**步骤条**（Step 1 选题 → Step 10 定稿），已通过=绿色✓、进行中=蓝色、未开始=灰色、回退=橙色
- 左侧：当前环节产物预览（题目/大纲/正文/参考文献）
- 右侧：操作区（按钮：执行当前环节/重新生成/导出 docx/运行全部）
- 底部：历史记录/回退日志

【页面3 文献调研（标准检索通道）】
- 顶部：检索输入框 + 范围下拉（全部/英文/中文）+ 源勾选（Crossref/OpenAlex/S2/知网引导/NCPSSD/ChinaXiv）
- 中间：检索结果列表（每行：标题/作者/年份/期刊/可靠度徽章[verified/matched/discovery]/GB/T 7714 复制按钮/【跳转下载】按钮）
- 右侧：已选文献池面板（勾选后加入，显示数量 + 导出/生成参考文献）
- 底部：标准检索通道说明（登记平台表）

【页面4 知识库（双链笔记）】
- 左侧：笔记目录树（按会话分组，含文献与笔记）
- 中部：**TipTap 笔记编辑器**（支持 `[[双链]]` 自动补全、Markdown、保存）
- 右侧：**反向链接面板**（显示哪些笔记引用了当前笔记）
- 底部状态栏：字数/保存状态

【页面5 知识图谱（Obsidian 式关系图）】
- 占满画布：**力导向关系图**（节点=笔记/文献，边=[[引用]]）
- 节点样式：文献=蓝色方块、笔记=绿色圆点、按引用数大小缩放
- 左侧工具栏：深度/节点大小/边显示/缩放/中心聚焦当前笔记
- 节点点击：弹出笔记预览卡片（标题+摘要+跳转编辑）

【页面6 任务设置】
- 表单：API 配置（DeepSeek key/BYOK 秘塔 key 可选）、检索默认范围、文献目标数量、docx 模板上传
- 注释框：说明"中文平台为引导层，用户自行下载到会话知识库"

每个页面给出：布局草图（方框/箭头表示组件位置）、关键交互（点击哪里发生什么）、
配色建议。不用写代码，重结构重信息层级。输出形式：Figma/HTML wireframe 或文字描述均可。
```

## 二、我们产品 UI 功能清单（概念图核对用）

### 全局
- 顶部导航：任务列表 / 知识库 / 检索 / 设置
- 右侧用户/会话切换器
- 深色模式（可选）

### 页面1 任务列表（工作台首页）
| 部件 | 说明 |
|---|---|
| 统计卡片 | 总任务数 / 进行中 / 已完成 / 知识库文献数 |
| 任务卡片网格 | 题目 + 学位标签（本科/硕士/博士）+ 进度条 + 当前环节 + 更新时间 |
| 新建任务按钮 | 模态框：题目 / 学位 / 学科域 / 检索范围（english/chinese/all） |
| 删除/归档 | 任务操作 |

### 页面2 论文流程详情（10 环节）
| 部件 | 说明 |
|---|---|
| **10 步步骤条** | Step1 选题→Step10 定稿；状态色（✓通过/进行中/未开始/回退） |
| 当前环节产物面板 | 题目候选 / 大纲 / 章节正文 / 参考文献（GB/T 7714 列表） |
| 操作按钮 | 执行当前环节 / 重新生成 / 导出 docx / 运行全部（演示用） |
| 评审拦截提示 | 环2/4 未通过时橙色警告条 + "回退环1 换题"建议 |
| 回退历史 | 底部时间线（何时回退到哪环） |

### 页面3 文献调研（标准检索通道）
| 部件 | 说明 |
|---|---|
| 检索框 + scope 下拉 | 全部 / 英文 / 中文 |
| **源勾选** | Crossref / OpenAlex / Semantic Scholar（已启用）+ 知网引导 / NCPSSD / ChinaXiv（登记位） |
| 结果列表行 | 标题 / 作者 / 年份 / 期刊 / **可靠度徽章**（verified 绿 / matched 蓝 / discovery 灰 / uncertain 橙色"待人工"） |
| 每行操作 | 复制 GB/T 7714 / 【跳转下载】（中文引导→打开平台搜索页）/ 加入文献池 |
| 右侧已选池 | 数量 + 导出参考文献（GB/T 7714 格式）/ 生成综述 |
| 底部说明 | 标准检索通道登记平台表（平台名/语言/是否 API/合规） |

### 页面4 知识库（双链笔记）
| 部件 | 说明 |
|---|---|
| 左侧目录树 | 按会话分组：笔记 / 文献（用户下载的 PDF/题录） |
| 中部编辑器 | TipTap：Markdown + `[[双链]]` 自动补全（输入 `[[` 弹笔记列表）+ 段落/表格 |
| 右侧反向链接面板 | "被 X 篇笔记引用：…" 点击跳转 |
| 保存按钮 | 保存触发后端增量索引 |
| 文献详情 | 文献 PDF 预览（可选）/ 题录编辑 / GB/T 7714 复制 |

### 页面5 知识图谱
| 部件 | 说明 |
|---|---|
| 力导向图 | Cytoscape.js：节点=笔记/文献（颜色区分：文献蓝方块/笔记绿圆点，大小∝被引数） |
| 左侧工具栏 | 深度 / 节点大小 / 边显示开关 / 缩放滑块 / 聚焦当前笔记 |
| 节点点击 | 弹出预览（标题+摘要+无预览→跳编辑） |
| 悬空链接 | 边虚线（目标还不存在的笔记） |

### 页面6 设置
| 部件 | 说明 |
|---|---|
| LLM API key | DeepSeek key（THESIS_DEEPSEEK_API_KEY 可改） |
| 秘塔 BYOK | 可选（用户自填，默认关闭，爸爸不承担成本） |
| 检索默认范围 | all / english / chinese |
| 文献目标数量 | 本科3w字/硕士8w/博士15w（学位路由） |
| docx 模板上传 | 用户学校模板（M5 解析） |
| 说明文本 | "中文平台为引导层：用户点击跳转下载，存到会话知识库文件夹" |

## 三、交互细节（概念图需体现）

1. **新建任务**：表单必填（题目/学位/学科域），检索范围默认"全部"
2. **执行环节**：点击"执行当前环节" → 按钮 loading → 完成后步骤条更新；评审未通过 → 橙色警告+回退按钮
3. **检索**：勾选源 → 点搜索 → 结果列表按可靠度着色；"加入文献池"累积到右侧
4. **笔记编辑**：`[[` 自动弹出笔记搜索框（输入过滤，回车创建新笔记）；双链在右侧显示反链
5. **图谱**：力导向自动布局；节点拖拽/缩放/居中；点击弹出预览卡
6. **所有页**：右上角"文档/API 参考"链接（Swagger）、"演示模式"按钮（跑全流程 demo）
