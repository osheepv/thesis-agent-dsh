## 一、一句话概述

这是一个**仿 Claude Code 桌面端**的"论文写作 Agent"前端原型：左侧会话列表（对话 = 会话 = 知识库 1:1），中间对话流 + 10 节点阶段进度条 + 人工确认闸门，右侧知识库面板（文献池/笔记/图谱），底部输入区（模型选择/模式/Ultracode 思考强度/上下文窗口）。**全部为静态演示数据 + 前端交互，无后端请求。**

### 给后端最关键的 3 个认知

1. **整个 UI 是单文件 HTML**，所有 CSS/JS 内联。要改 UI 只需改这一个文件。
2. **所有数据都是硬编码的"演示假数据"**（会话列表、消息、文献、进度条状态、上下文数值等），需要后端替换成 API 数据。
3. **交互全部在前端本地完成**（切换会话/主题/语言/模型/拖动滑块等），目前不持久化（仅语言选择存在 `localStorage`）。

## 六、组件清单与交互

> 每个组件列出：**HTML 位置 → 对应 ID/类 → 当前交互 → 后端接入点**。

### 6.1 会话列表（Sidebar）
- **结构**：`.session-list` 内按 `Today / Previous 7 Days` 分组，每项 `.session-item[data-session="N"]`
- **每项包含**：标题 `.session-title`、学位徽章 `.session-degree`、进度文本 `.session-progress-text`、进度条 `.session-progress-bar > .session-progress-fill`、删除按钮 `.session-delete`
- **当前交互**：点击切换选中态（品牌橙左侧竖条）；删除弹确认模态（提示"一并删除知识库"）
- **⚠ 后端接入**：会话列表数据是硬编码 4 条。接入 REST 后应改为 JS 渲染 `renderSessions(list)`；删除应调用删除接口。

### 6.2 阶段进度条（Main 顶部，10 节点）
- **JS 数据源**：`const STAGES = [ { name, state } × 10 ]`（state: `done | current | todo | gate`）
- **节点视觉**：`done`= 成功绿 ✓；`current`= 品牌橙 + 脉冲动画 + 外圈光晕；`todo`= 灰；`gate`= 权限蓝虚线圈旋转（评审关卡）
- **确认闸门按钮**（对话流中 `[data-gate]`）：点击后把 `current` 节点推进为 `done`、下一节点变 `current`，并更新连线
- **⚠ 后端接入**：进度来自后端会话状态。建议接口返回 `stages: [{name, state}]`，前端 `renderStages()` 重建进度条。

### 6.3 对话流（Main）
消息类型（按 `.msg.user / .msg.ai` 区分左右）：
| 卡片类型 | 类名 | 说明 |
|---|---|---|
| 用户消息 | `.msg.user .bubble` | 右对齐灰底 |
| AI 消息 | `.msg.ai .bubble` | 左对齐无底 |
| 工具调用卡 | `.tool-card` | 头部可点击展开 `.tool-card-body`（预格式化 JSON） |
| 产物卡 | `.artifact-card` | 文档产物预览 |
| 文献检索卡 | `.ref-card` | 左侧品牌橙边线；含可靠度徽章 `.badge.verified/matched/discovery/uncertain` |
| 警告卡 | `.warn-card` | 评审未通过（琥珀色），带"重新生成/回退"按钮 |
| 确认闸门 | `.gate-block` | 每环验收后出现，含 `[data-gate]` 按钮 |

- **⚠ 后端接入**：消息数组建议接口返回 `messages: [{role, type, content, tool?, refs?, badge?}]`，前端写 `renderMessages()` 渲染。工具调用卡/文献卡/警告卡/闸门块都应**由消息类型驱动生成**，而不是写死在 HTML。

### 6.4 输入区（Main 底部）

## 七、i18n（中英双语）

- **对象**：`const I18N = { 'zh-CN': {...}, 'en-US': {...} }`（`index.html` 内约 90 条键）
- **用法**：HTML 中 `data-i18n="key"`（文本）/ `data-i18n-placeholder="key"`（占位符）
- **函数**：`t(key)` 取翻译；`applyI18n()` 全量应用；`switchLang(lang)` 切换并持久化
- **当前语言**：`currentLang`（初始读 `localStorage['thesis-agent-lang']`，默认 `zh-CN`）
- **⚠ 后端接入**：新增文案时在 `I18N` 两个语言对象各加一条同 key 的翻译，然后在 HTML 加 `data-i18n="key"` 即可。

## 九、建议的 API 对接方案（供后端参考）

> 前端目前没有发任何网络请求。接入时可保持"前端只管渲染、后端给数据"的分工，推荐 REST 风格：

```
# 会话
GET    /api/sessions                     # 会话列表（含 degree、progress）
POST   /api/sessions                     # 新建对话（自动建知识库）
DELETE /api/sessions/{id}                # 删除会话（连带知识库）

# 对话
GET    /api/sessions/{id}/messages       # 历史消息（含类型：user/ai/tool/ref/warn/gate）
POST   /api/sessions/{id}/chat           # 发送消息 {content, mode, model, thinking}
GET    /api/sessions/{id}/stages         # 10 节点进度
POST   /api/sessions/{id}/confirm        # 确认进入下一环

# 知识库
GET    /api/sessions/{id}/kb/refs        # 文献池
GET    /api/sessions/{id}/kb/notes       # 笔记
GET    /api/sessions/{id}/kb/graph       # 图谱节点/边

# 推理配置（占位待实现）
GET/PUT /api/inference/provider          # 大模型 Provider/Key/模型/参数
```

前端接入策略建议：在 `<script>` 末尾加一个 `api.js` 区块（或直接新增一个 `<script src="api.js">`），封装 `fetch` 调用，并把上文"⚠ 后端接入"处标记的硬编码改为 `renderXxx(data)` 渲染函数。

## 十、修改 UI 的快速指南（给 Claude）

1. **改配色/圆角/间距** → 只改 `<style>` 顶部 `:root` 与 `[data-theme="dark"]` 的 Token 变量。
2. **改文案** → 优先用 `data-i18n` + `I18N` 对象；若临时写死，直接改 HTML 文本。
3. **改组件样式** → 组件类名集中在 CSS 各分区注释下（如 `/* Dropdown */`、`/* Popover */`），按分区搜索类名即可。
4. **改交互** → `<script>` 按模块注释分节（`/* 模型选择 */`、`/* Ultracode */`、`/* 设置面板 */` 等）。
5. **新增浮层** → 在 body 末尾加 DOM，类名复用 `.dd-menu`（下拉）或 `.popover`（气泡），用 `openDd()` / `openPopover()` 定位。
6. **新增翻译** → `I18N` 两个语言对象加同 key；HTML 加 `data-i18n`。
7. **可访问性基线**：所有可点元素有 `:focus-visible` 外框；滑块/开关带 `aria-*`；`prefers-reduced-motion` 已支持。
