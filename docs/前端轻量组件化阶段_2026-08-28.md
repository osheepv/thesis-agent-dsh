# 前端轻量组件化阶段

## 目标

本阶段不改视觉、不改API、不引入框架或npm构建，只建立第一个可维护的前端模块缝。

## 结果

- `index.html`由约316KB降至约45KB，只保留文档结构和静态资源引用；
- 约80KB样式转移到`ui/styles/app.css`；
- 主运行时转移到`ui/js/app.js`；
- 项目记忆形成第一个真实功能模块`ui/js/components/project-memory.js`；
- 证据与论证概览迁入`ui/js/components/evidence.js`，只暴露`window.ThesisEvidence.loadPanel()`；
- 证据面板使用请求版本号拒绝过期并发响应，并对证据审计、来源账本和论证图的局部失败分别呈现；
- 主运行时只通过`window.ThesisProjectMemory`使用项目记忆的加载和提交接口；
- 启动方式仍是`cd ui && python -m http.server 8787`。

## 为什么暂不使用ES Module

当前仍有内联事件处理器，而且`app.js`在文档底部立即执行`initApp()`。直接改为`type="module"`会使现有全局函数不再对内联处理器可见，属于不必要的大范围行为变更。本阶段保留classic script，用明确加载顺序和小接口降低风险。
