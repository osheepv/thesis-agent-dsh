# 前端 UI 生成提示词（概念图 / 设计稿用）

> 用途：拿着这份需求让 AI（Figma First Draft / Cursor / 即梦 等）生成**产品 UI 概念图/线框图**，
> 生成后发回来，我照着图纸实现前端代码。
> 技术栈：React + Vite + antd 5 + ProComponents + TipTap（编辑器）+ Cytoscape.js（图谱）。
> **产品定位：AI Agent 桌面客户端**（后续 Tauri 打包成 desktop），
> **界面风格直接参照 Codex / Claude Code / DeepSeek Harness (dsh) 的桌面版**——
> 对话流为主、左侧会话列表、状态内联徽章，**不是仪表盘/后台**。

---

## 一、给 AI 的提示词（直接复制）

### 风格基准（每段提示词开头都带上）

> **设计风格：完整复刻 Codex / Claude Code / DeepSeek Harness 桌面客户端的视觉语言**——
> 顶部极简工具栏（Logo + 会话名），左侧窄栏会话/任务列表（小图标+条目，选中态高亮），
> 主区是**对话流**（用户消息 + AI 消息，AI 消息含 Markdown 渲染、卡片、状态徽章），
> 底部大输入框（对话式发送 + 上下文徽章），右侧为可折叠详情面板。
> 细节：深色 + 浅色双主题（默认深色），Monospace 字体点缀（路径/JSON/代码），
> 卡片圆角 8px、浅灰分隔线、高信息密度，现代极简，无仪表盘感。

### 主界面（最核心，只此一页）

```
Web Dashboard「论文写作 Agent」，**完整复刻 Claude Code / Codex 桌面客户端首页**：
顶部工具栏（高 48px，深色）：左侧 Logo + 当前会话标题 + 中间快捷操作（新建任务/全部运行/
设置，图标按钮），右侧用户头像。
左侧栏（宽 240px，可折叠）：分两组——
  A) 任务/会话列表：竖排条目，每条含标题/学位标签(本|硕|博)/状态徽章(进行中●/已完成✓)/
     最近更新时间，当前项深色高亮；
  B) 底部两个页签：知识库（文件树：会话分组→笔记/文献，可展开）/ 检索（快捷检索入口）。
中部主区（对话流）：
  - 第一屏：欢迎消息（"选择或新建一个论文任务开始"）+ [新建任务卡片]（表单：题目/学位/学科域/
    检索范围下拉，内联在对话流里）。
  - 用户消息（右侧对齐，气泡）："帮我生成论文《基于轻量化Transformer的遥感图像分割》"。
  - AI 回复（左侧，Markdown 渲染）：环1 步骤条 + 候选题目卡片（4 个候选，可点选）+ 
    "继续"按钮；后续每环 AI 消息内联：环N 名称 + 状态徽章（✓通过/⚠️评审未通过/🔍检索中）+
    产物缩略卡片（可展开查看大纲/正文/参考文献），10 环完成时显示定稿汇总卡片。
  - 流式打字效果（AI 回复逐字出现，状态徽章实时更新）。
底部输入框（宽 620px 居中，大、圆角）：placeholder"输入指令，如：继续执行下一环节 / 检索…
  + 发送按钮 + 上下文徽章（当前会话/当前环/文献池篇数）。
右侧详情面板（宽 300px，可折叠，点击步骤条/卡片时展开）：当前环节详细产物 +
  回退历史时间线 + 操作按钮（重新生成/导出 docx/回退）。
严格按 Claude Code 桌面版的中性色（背景 #0d1117/#1f2328、文字 #e6edf3、主色蓝 #3b82f6、
成功绿 #22c55e、警告橙 #f59e0b），Monospace 用于路径/代码，对话区行距宽松。
```

### 知识库（双链笔记）——点击左侧页签进入

```
Web Dashboard「知识库」，参照 Claude Code / Codex 的文件树 + Obsidian 编辑器混合：
左侧栏切换为文件树（会话→笔记/文献，图标：笔记📄/文献📑，双链笔记标题），
中部：Markdown 编辑器（TipTap：标题/段落/代码块，输入 [[ 弹笔记搜索自动补全，
双链显示为浅蓝内联链接），
右侧面板（宽 280px）：反向链接列表（"被 N 篇笔记引用"）+ 文献题录（DOI/作者/年份/
GB/T 7714 复制按钮），
底部：保存状态 + 字数。风格延续主界面深色主题，编辑器区浅一点（深色编辑区）。
```

### 知识图谱——点击左侧页签进入

```
Web Dashboard「知识图谱」，参照 Claude Code / Codex 的"知识图谱"视图（如 dsh 的图谱）：
全画布力导向关系图（深色背景：节点=笔记/文献，文献=蓝色方块/笔记=绿色圆点，
大小按被引数，边=半透明线，悬空链接虚线），
左上浮动工具栏（半透明胶囊：深度滑块/节点大小/边开关/缩放/聚焦当前笔记），
节点点击弹出预览卡片（标题+摘要+打开编辑），背景深色延续主主题。
```

### 设置——点顶部齿轮进入

```
「设置」，参照 Claude Code / Codex 的设置面板（左侧列表+右侧表单，深色）：
左侧分类列表：模型 / 检索 / 知识库 / 模板 / 关于；
右表单：DeepSeek API Key（显示隐藏）| 秘塔检索 Key（可选 BYOK）| 检索默认范围下拉 |
文献目标数量 | docx 学校模板上传（拖拽），底部灰色说明"中文平台为引导层，
用户自行下载文献到会话知识库文件夹"。
```
