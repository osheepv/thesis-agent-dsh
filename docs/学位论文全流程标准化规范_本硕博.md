# 学位论文标准化全流程规范（本科 / 硕士 / 博士）

> 本文档面向「论文全流程自动化 Agent」的开发者，以**可落地的状态机视角**梳理学位论文从选题到定稿的完整链条。
> 读者对象：需要把本硕博论文流程抽象成可执行、可校验、可回退的 Agent 编排者。
> 数据来源说明：凡涉及"新颖度评估 / 文献调研 / 研究热点 / 前沿脉络"的环节，标注了可对接万方数据官方接口的落地位（见第 7 章），供后续 Agent 真实取数；**本文正文给出的里程碑、验收阈值、差异对比属于行业通行的质量标准与规范沉淀，不构成对任何具体学科方向的文献结论。**

---

## 0. 文档定位与如何使用

### 0.1 这份文档解决什么问题
把「一篇学位论文是怎么写成的」抽象成 **10 个可验收的环节**，并给每个环节提供：
- **输入 / 输出**（Agent 之间传递的"状态"）
- **核心验收标准**（机器可判定的"通过条件"）
- **常见分支场景**（什么时候走回退、什么时候走旁路）
- **本硕博差异**（同一个环节在本科/硕士/博士手上的不同要求）
- **学术规范要求 + 踩坑清单**（容易被扣分、被查重的硬伤）
- **接口落地位**（哪些环节、哪些判断可由万方数据真实支撑）

### 0.2 Agent 怎么读它
建议把流程建模为 **有限状态机（FSM）**，每个环节是状态，验收不通过就回到指定前置状态（回退环）。本硕博三类差异用 **"学位等级"路由参数** 在同一个状态机内分流，而不是开三套流程——因为各环节的**骨架相同**，只是**阈值、深度、创新要求**不同。

### 0.3 全局红线（任何环节都不可违反，置顶）
1. **真实数据优先**：凡评估类、调研类结论（新颖度、研究现状、学术空白、热点趋势），必须来自真实数据库检索，禁止大模型凭空编造文献、申请号、数据结论。
2. **查重与规范红线**：引文必须真实可溯（篇名/作者/刊名/年份/卷期页对得上）；不得代写、不得伪造实验数据、不得避开"学术不端"审查。
3. **知识产权与伦理**：涉人体/动物实验需伦理批号；涉数据需注明来源与授权；涉机密不得引用。
4. **平权表达**：文档正文及所有产物不得使用以女性身体/贞洁为隐喻的描述性词汇（如"处女地""处女作"），统一改用中性表述（"空白领域""开山之作"等）。

## 1. 全流程总览

### 1.1 环节链（10 环）

```
[1 前期选题]
    ↓
[2 新颖度评估]  ←——————【回退：新颖度不足 → 回到 1 换题/收敛】
    ↓
[3 文献调研]
    ↓
[4 文献综述]
    ↓
[5 论文大纲搭建]
    ↓
[6 分章节撰写]
    ↓
[7 修改润色]
    ↓
[8 引用/参考文献校验]
    ↓
[9 格式排版]
    ↓
[10 最终定稿]
```

### 1.2 三类学位在链条上的**差异本质**（一句话总纲）
- **本科（学士论文）**：目标是"**规范地完成一个限定问题**"——重流程规范、重完整性，**创新性要求最低**（"有一点自己的想法即可"），篇幅小、文献少、分析浅。
- **硕士（学硕/专硕）**：目标是"**解决一个真实问题并证明可行性**"——重方法、重数据、重可复现，**要求有明确的创新点**（通常是"方法改进/场景迁移/模型适配"），文献要求中等偏上。
- **博士（学位论文）**：目标是"**做出该领域被认可的原创性贡献**"——重理论深度、重体系性、重前沿性，**创新性要求是硬门槛**（要有真正的新理论/新方法/新发现，并回答"前人为什么没做到"），文献覆盖面与深度远超前两者。

> 差异最集中的三个环节：**① 新颖度评估（创新要求）**、**② 文献综述（深度与覆盖面）**、**③ 分章节撰写里的"研究设计/结论"（贡献论证）**。其余环节（选题、调研、大纲、润色、引用、排版）骨架基本一致，仅在阈值上区分。

## 环节 1：前期选题

### 1.1 定义
确定研究问题（Research Question）与研究范围，形成候选题目。是所有后续环节的地基，**选题质量决定论文上限**。

### 1.2 输入 / 输出
- 输入：学科领域、学位等级、导师方向、兴趣点、当前时间窗口（需考虑前沿性）。
- 输出：**≥1 个候选题目**，每个附：拟解决的问题、研究范围边界、一句"为什么值得做"。

### 1.3 核心验收标准
- ✅ 题目落在本学科真实问题域内，不是伪命题。
- ✅ 问题**明确、可界定**（能说清楚"研究对象、研究范围、研究问题"三者）。
- ✅ 一句能说清"我到底想解决什么"（电梯陈述）。
- ✅ 没有撞上已被做滥的话题（需接第 2 环节验证）。
- ✅ **符合学位等级定位**：本科守住"限定小问题"，博士守住"有原创空间的真问题"。

### 1.4 常见分支场景（含回退）
- **分支 A｜题太大（贪多）** → 信号：问题域覆盖过宽、写不完。**处理**：收窄范围、增加限定词（时间/地域/样本/场景），回退到 1 重选题面。
- **分支 B｜题太小（无价值）** → 信号：一眼看出答案或已有标准做法。**处理**：升维，加入更广的变量或现实情境，或换一个更值得研究的问题面。
- **分支 C｜题太旧（冷门但非空白）** → 可能意味着已过研究热潮或本身无研究价值。**处理**：结合热点脉络判断是"空白机会"还是"无价值"，传导到环节 2 判定。
- **分支 D｜缺导师/资源支持（工具、数据、经费不可得）** → **处理**：早期就核实可行性，不可行立即换题，避免后期崩盘。

### 1.5 本硕博差异
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 题目规模 | 限定、小巧 | 中等、有边界 | 体系化、有纵深 |
| 问题来源 | 多为导师给定/课程延伸 | 真实需求或文献缺口 | 领域前沿疑难点 |
| 选题自由度 | 低 | 中 | 高（但须原创） |
| 题目预计占据的创新义务 | "有一点想法即可" | "明确的创新点" | "原创性贡献" |

### 1.6 高频规范要求
- 题目用词精准、无歧义，避免绝对化（"首次""唯一""最优"）。
- 学位论文题目一般简明，不含副题（除非必要），理工类常带限定词（方法+对象）。

### 1.7 踩坑清单
> - 🚨 **拍脑袋选题**：没做前期调研就定题，新颖度评估阶段必然翻车（回到环节 2 会卡住）。
> - 🚨 **题目与正文不匹配**：写了三年，最后题目和内容两张皮。
> - 🚨 **题目堆砌关键词**：为"看起来全"而罗列，削弱明确性。
> - 🚨 **忽略可行性**：大而空、无数据无工具无样本，导致后期无法实证。

### 1.8 接口落位（可对接万方）
- 选题初筛可对接「万方学术主题分布」「万方交叉学科分布」判断该问题属于哪个主题、有无被充分研究。
- 与候选题目同义/相近主题可直接用「万方关联主题词」扩展关键词集，辅助圈定范围。

### 1.9 回退逻辑
⇦ 若环节 2 判定新颖度不达标 → **回退到环节 1** 换题或收敛；若环节 6 发现某分支写不下去 → 回到环节 1 重划范围（需谨慎，改动越大回退越深）。

## 环节 2：新颖度评估

### 2.1 定义
对候选题目做"别人是否已经做过、做得如何、我还有没有空间"的判断。**这是本硕博差异最剧烈的一环**，也是"学术查新"的核心。

### 2.2 输入 / 输出
- 输入：候选题目、关键词集、研究范围。
- 输出：**新颖度结论**（高/中/低）+ 风险说明 + 是否进入下一环节的"放行/回退"标志。

### 2.3 核心验收标准
- ✅ 检索到**同题或高度相似**的研究，并说明其局限（这正是你切入的空间）。
- ✅ 能明确回答"**你的工作与前人最大的不同在哪**"。
- ✅ 对**硕士**：有至少 1 个明确的改进/迁移点；对**博士**：有至少 1 个实打实的原创贡献点（见 2.5）。
- ✅ 新颖度结论有真实数据支撑（检索结果），而非凭感觉说话（符合全局红线）。

### 2.4 常见分支场景（回退核心逻辑）
- **分支 A｜同题已有人做，且做得很成熟** → 新颖度低。**处理**：换角度/换场景/换方法，或直接回退环节 1 换题。
- **分支 B｜同题有人做，但有明显局限（样本小、未实测、场景单一）** → 新颖度中高。**处理**：定位为"在某方面补足/改进"，这是硕士最稳的创新思路。
- **分支 C｜几乎没人做（空白）** → 需区分：是"真空白机会"还是"无研究价值/无数据/伪命题"。**处理**：联系可行性核实，切勿把"没人做"当"值得做"。
- **分支 D｜交叉学科（跨领域）** → 新颖度往往较高，但需防"两边都不精"的尴尬。**处理**：明确主学科，界定交叉边界。

### 2.5 本硕博差异（创新点要求，最关键的差异）
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 创新性门槛 | 极低 | **中（硬性要求）** | **极高（决定性要求）** |
| 创新类型 | 有个"自己的想法"即可 | **方法改进/场景迁移/模型适配/数据新** | **新理论/新方法/新发现/新体系** |
| 是否需要回答"前人为何没做到" | 否 | 简单提及 | **必须系统论证** |
| 创新点数量 | 0~1 | 1~2 | 多个并形成体系 |
| 新颖度判定灵敏度 | 低（不强制查新） | 中（需查新支撑） | 高（查新是硬门槛） |

### 2.6 高频规范要求
- 查新结论需说明检索范围（数据库、时间窗、关键词组合），保证可复核。
- 需列出"相似研究"清单及其局限，作为创新切入的论证。
- 严禁引用不存在/张冠李戴的"相似研究"（学术不端红线）。

### 2.7 踩坑清单
> - 🚨 **把"没查到"当成"没人做过"**：要区分"库中无沉淀（空白机会）"与"网络超时没取回（可能其实有）"。
> - 🚨 **过度拔高创新性**：用"首次/独创/填补空白"等绝对词，一旦被质疑即翻车。
> - 🚨 **博士论文创新点过散**：东一个点西一个点，不成体系，评审视为"堆砌"。
> - 🚨 **忽略防查重风险**：为追求新颖而造词、造概念，反而评审不认。

### 2.8 接口落位（可对接万方）
- 核心引擎：**「万方研究前沿脉络库」** 判断该方向是否已形成成熟研究脉络、热度如何；
- **「万方新兴主题库」** 看该方向是否为新兴主题（空白/新热点信号）；
- 相似研究扫描：检索同题/近题文献及其局限（评估其成熟度与空间）；
- 需要量化"至少 50 篇"这类**召回上限**时才触发真实检索；本文档的阈值与口径不替代真实检索。

### 2.9 回退逻辑
⇦ **本环节是"回退枢纽"**：新颖度不达标 → 回退环节 1 换题；新颖度达标但需换角度 → 轻微回退调整关键词与范围即可，不必重换题。

## 环节 3：文献调研

### 3.1 定义
系统搜集与主题相关的文献（期刊、硕博论文、专著、会议、报告），构建**证据池**，支撑综述与论证。

### 3.2 输入 / 输出
- 输入：主题关键词、范围、学位等级。
- 输出：**文献清单**（题录 + 摘要 + 分类），按"理论/方法/实证/综述"等维度归档。

### 3.3 核心验收标准
- ✅ 检索覆盖关键数据库与年限范围，检索式可回溯。
- ✅ 收集到**主干文献**（该领域公认的代表性研究）+ **最新前沿**（近年）两端。
- ✅ 文献按主题/流派归类，便于后续综述与大纲引用。
- ✅ 数量质量特征符合学位等级（见 3.5）。

### 3.4 常见分支场景
- **分支 A｜文献太少（方向太窄/太新）** → 可能是空白（机会）也可能检索式不当。**处理**：扩展同义词、放宽时间窗、跨学科检索，仍少则走"空白机会"路线。
- **分支 B｜文献太多（方向过热）** → 说明拥挤，需找出差异化切入，并筛选出核心文献聚焦。
- **分支 C｜关键文献难获取（付费/非公开）** → 需判断可用替代（相近文献、综述转引，但仍需原始核对）。

### 3.5 本硕博差异（文献数量与深度）
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 文献量 | 少（满足综述即可，通常 30 篇上下视学科，**属"够了就行"**） | 中（覆盖主干 + 近年，通常 50~80 篇） | 大+深（**要求体系化、穷尽主干**，通常百篇级且须精读经典） |
| 外文文献比例 | 占比低 | 中 | **高（须大量国际前沿）** |
| 是否为"必须补上的一环" | 可简化 | 必须系统 | 必须穷尽且批判 |
| 文献时效性 | 一般 | 注重近 5 年 | **要求追踪最新前沿（1~3 年）** |

### 3.6 高频规范要求
- 区分**一手文献/二手文献**，综述以一手为主，重要结论尽量引原文。
- 标注文献类型（期刊/学位/会议/专著），避免混用。
- 记录每篇文献的完整题录（作者/标题/刊名/年/卷期页），供环节 8 校验。
- 严禁虚假文献、张冠李戴、掐头去尾（过度改写导致误读原意）。

### 3.7 踩坑清单
> - 🚨 **只堆数量不消化**：列了一堆文献但没读透，综述变成"书目清单"。
> - 🚨 **混淆文献综述与文献罗列**：综述要"评"不是"抄"。
> - 🚨 **引用二手信息当一手**：转述误读，甚至引错观点归属。
> - 🚨 **文献陈旧**：学科迭代快（如 AI/医学），用了 5 年前过时结论。

### 3.8 接口落位（可对接万方）
- 文献检索：用「万方文献库检索」按关键词+年限+学科范围取题录与摘要。
- 找代表性学者：用「万方学者库检索」定位主轴人物与团队（供综述"主流阵营"）。
- 期刊选题指南/学科分类/选题指导：可用「万方期刊选题学科分类」「万方期刊选题指南」辅助锁定主流研究阵地。

### 3.9 回退逻辑
⇦ 若环节 4 综述发现证据不足 → 回退到 3 补检索；若文献质量不足以支撑创新 → 回到 3 扩大范围或回到环节 1 调整问题。

## 环节 4：文献综述

### 4.1 定义
对第 3 环节的证据做**批判性整合**：梳理研究脉络、识别争鸣与空白，为论文立论并**包住创新点**。

### 4.2 输入 / 输出
- 输入：文献清单 + 分类。
- 输出：**综述章节**（研究现状 + 不足 + 你的研究切入点）。

### 4.3 核心验收标准
- ✅ 按主题/流派/时间线**结构化**呈现，非流水账罗列。
- ✅ 指出已有研究的 **局限/争鸣/未解问题**（这是立论基础）。
- ✅ 综述末尾自然引出你研究的**必要性**（衔接环节 2 的创新点）。
- ✅ 覆盖主干 + 前沿两端，论证有逻辑链。
- ✅ 符合学位等级深度（本科浅、硕中、博深）。

### 4.4 常见分支场景（含回退）
- **分支 A｜综述与冲突文献矛盾**（已有研究结论相反） → 需明确**学术争鸣**，站在哪一方或提出调和，不能含糊带过。
- **分支 B｜综述暴露创新点已有人做** → 实时反馈：新颖度受冲击，**回退到环节 2 重评估**极可能换角度。
- **分支 C｜综述写成了罗列**（无评述） → 判定为不合格，重写（常见初级错误）。

### 4.5 本硕博差异
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 综述性质 | 介绍性总结 | 分析性总结 | **批判性综述（建构自身理论立场）** |
| 是否有"自己的框架" | 基本无 | 有简述 | **必须提出自己的分类/框架/脉络** |
| 是否需"评" | 弱 | 中 | **强** |
| 是否覆盖国际前沿 | 弱 | 中 | **强** |

### 4.6 高频规范要求
- 综述逻辑线清晰：**按问题演进/流派/方法**组织，比按"文献出现顺序"好。
- 每段先概括、再评点、最后落到与本文的关系（"三段式"观点化表达）。
- 批判性但不失礼貌，明确指出局限即可，避免偏激。
- 防止"证据堆砌"，要有作者自己的判断。

### 4.7 踩坑清单
> - 🚨 **综述与选题脱节**：综述讲 A 方向，论文做 B 方向（两张皮）。
> - 🚨 **只综不述**：全篇"某某认为/某某发现"，没有作者声音。
> - 🚨 **罗列堆砌**：按时间流水账或按作者重复，无主题归类。
> - 🚨 **漏掉关键争鸣**：回避了该领域真正的争议，评审会认为不专业。

### 4.8 接口落位（可对接万方）
- 「万方研究前沿脉络库」提供该领域的发展脉络、趋势，供综述"阶段划分"与"现状定位"。
- 「万方研究趋势报告」辅助趋势性归纳（前沿/演进/热度变化）。
- 「万方学者库检索」梳理主流阵营与代表性人物观点。

### 4.9 回退逻辑
⇦ 综述结论与创新点冲突 → 回退环节 2；综述证据不足 → 回退环节 3 补料。

---

## 环节 5：论文大纲搭建

### 5.1 定义
将研究问题拆解为**章节结构**（章/节/小节 + 每节任务与预期内容），作为撰写蓝图。

### 5.2 输入 / 输出
- 输入：研究问题、综述结论、创新点、研究设计（方法/数据）。
- 输出：**结构化大纲**（建议到三级标题 + 每节要点/目标字数/证据要求）。

### 5.3 核心验收标准
- ✅ 大纲能完整覆盖"提出问题 → 论证问题 → 解决问题 → 总结"的闭合逻辑。
- ✅ 与创新点强绑定：**每章都有明确"服务于哪个贡献"的定位**。
- ✅ 章节层级清晰（章/节/小节不混乱），编排符合学科惯用结构。
- ✅ 长度与结构符合学位等级（本薄、硕中、博深且可含独立成果章节）。

### 5.4 常见分支场景（含回退）
- **分支 A｜大纲逻辑断链**（前后章节不衔接） → 回退重排，补逻辑桥段。
- **分支 B｜某章预期贡献与创新点冲突/重复** → 回退收敛，避免虚章。
- **分支 C｜博士发现需要额外独立章节（如方法论/实验体系）** → 大纲动态扩容，但要保整体一致性。

### 5.5 本硕博差异
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 章节数 | 少（通常 3~5 章类） | 中（4~6 章类） | 多（5~8 章类，可含成果章节） |
| 结构自由 | 低（多套用模板） | 中 | 高（可自定义体系） |
| 是否允许"独立创新章节/专利章" | 否 | 少 | **是（突出原创贡献）** |
| 对理论框架的要求 | 弱 | 中 | **强（需有理论/分析框架）** |

### 5.6 高频规范要求
- 遵循学科规范结构（理工：绪论—相关/方法—实验/实现—结果—结论；社科：绪论—文献—理论/假设—方法—分析—结论）。
- 避免双层标题、层次跳跃；标题简洁明确不加副题/夹带。
- 每节配"目标 + 预期证据 + 预期字数"，便于自动化 Agent 分派撰写任务。

### 5.7 踩坑清单
> - 🚨 **大纲与正文脱节**：大纲定得漂亮，写起来跑偏，最后返工。
> - 🚨 **结构模块化套模板**（尤其本科）导致逻辑僵化、与问题错配。
> - 🚨 **缺少"研究方法/设计"章节**：实证类论文缺方法，评审直接不行。
> - 🚨 **结论与前期论证脱节**：结论没有紧扣每章论证，显得突兀。

### 5.8 接口落位
- 大纲阶段侧重结构方法，**无直接万方检索需求**；但章节"研究现状/文献"部分需引用环节 3/4 的文献池，保持引用连续性。

### 5.9 回退逻辑
⇦ 若环节 6 撰写中发现某章无法支撑（缺证据/缺方法） → 回退到 5 修订大纲或回退到 3 补文献/数据。

---

## 环节 6：分章节撰写

### 6.1 定义
按大纲逐章填充内容。**是耗时最长的环节，也是本硕博差异在"研究设计/贡献论证"上集中体现的环节。**

### 6.2 输入 / 输出
- 输入：大纲、文献池、研究数据/实验结果、创新点。
- 输出：**各章节草稿**（逐步产出，供润色）。

### 6.3 核心验收标准
- ✅ 各章完成大纲预设任务，逻辑闭环。
- ✅ **实证/研究设计章节**：方法描述可复现（样本、工具、流程、指标）。
- ✅ **结果与讨论**：证据支撑结论，不做无据推断；数据真实。
- ✅ **创新点论证**：专章或专节回答"前人为何没做到、我做到哪一步"。博士尤其强。
- ✅ 章节间有过渡、首尾呼应；长度符合学位等级。

### 6.4 常见分支场景
- **分支 A｜数据结果不支持原假设/结论** → 诚实面对：讨论"与预期不符"的原因，**不要篡改数据**（学术不端）。这正是很多论文的"意外发现"价值点。
- **分支 B｜某节证据不足、论证空洞** → 回退补证据（数据/文献/实验）。
- **分支 C｜写作跑题，偏离大纲** → 回退校正，以大纲为锚。
- **分支 D｜创新点论证薄弱**（博士尤其） → 强化"对比前人 + 定位自身贡献"，回退补论证。

### 6.5 本硕博差异（研究设计的创新要求）
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 研究方法深度 | 基础/模板 | 成熟方法 | **自建方法/体系/创新实验** |
| 数据/实验要求 | 简单 | 真实可靠可复现 | **体系化、多方位验证** |
| 创新论证强度 | 弱 | 中（与已有对比即可） | **强（系统性论证原创性，回答"差在哪"）** |
| 是否允许只做"应用" | 是 | 是（改方法/迁移场景） | **否（须有原创理论/机制/发现）** |
| 对"前人为何没做到" | 不强制 | 简述 | **必须系统回答** |

### 6.6 高频规范要求
- 实证部分：方法、样本、指标、流程可复现；数据引用注明来源。
- 讨论部分：结果解读合理、不夸大、与已有研究对话。
- 逻辑与学术用语：避免绝对化、避免口语化，避免大段堆砌。
- 严谨的知识归属：每个观点/数据/图表要有来源（引文或数据注）——否则环节 8 会爆雷。

### 6.7 踩坑清单
> - 🚨 **篡改/编造数据、实验**：学术不端，一票否决。
> - 🚨 **结果与结论脱节**：结论推不出结果支撑的高度。
> - 🚨 **方法不可复现**：样本、参数、流程含糊，评审质疑科学性。
> - 🚨 **创新点论证泛泛而谈**：只说自己"新"，不对比前人、不划边界。
> - 🚨 **过度堆砌图表**：图表应有解释、有讨论，不是贴上去就完事。

### 6.8 接口落位
- 撰写阶段核心是"论证落地"，主要依赖环节 3/5 的产物，无强外部取数需求；若某章需补"最新研究现状"可回查万方文献库。

### 6.9 回退逻辑
⇦ 每章完成后做"可复现性与证据充分性"自检，不通过 → 回退到本环节重写本段，或回退到 5 调整大纲、到 3 补证据。

---

## 环节 7：修改润色

### 7.1 定义
在初稿基础上做**内容打磨**（逻辑、语言、结构）与**形式统一**（术语、图表、编号），不留作文体粗糙与逻辑硬伤。

### 7.2 输入 / 输出
- 输入：全稿（或各章稿）。
- 输出：**润色稿**（内容与语言质量提升，结构更顺）。

### 7.3 核心验收标准
- ✅ 逻辑通顺、段落衔接自然、无重复与赘述。
- ✅ 术语统一；学术用语规范、客观、避免口语/广告式表达。
- ✅ 图表有编号、有标题、正文有引用指引；全文编号连续。
- ✅ 消除绝对化表述、消除夸张（"巨大突破""史上最"）。
- ✅ 语言符合学位等级（本科文风可浅，博士力求严谨精炼）。

### 7.4 常见分支场景
- **分支 A｜长句过多、可读性差** → 拆分与重构。
- **分支 B｜逻辑重复/论证跳跃** → 回退到 6 重写相关段，而非仅改文字（润色不改内容的错）。
- **分支 C｜术语前后不一** → 全局统一术语表（避免同一概念多种叫法）。

### 7.5 本硕博差异
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 语言严谨度 | 基本通顺 | 规范 | **精炼、深度、有学术功底** |
| 术语体系要求 | 宽 | 规范 | **自成体系** |
| 润色重点 | 通顺+规范 | 逻辑+专业 | **深度+原创性表达的打磨** |

### 7.6 高频规范要求
- 学术语体：客观、第三人称为主、避免情绪化。
- 避免一词多义、避免中英混用随意、（理工）公式/符号统一。
- 避免"我认为"式主观论证泛滥（可保留必要学术判断，但要克制）。

### 7.7 踩坑清单
> - 🚨 **把润色当改写**：为追求"流畅"而乱改专业内容、影响科学准确性。
> - 🚨 **只改字不改逻辑**：句子通顺了但论证仍是断的（治标不治本）。
> - 🚨 **风格飘忽**：各章文风不统一（不同人/不同时间写作导致），需统一。
> - 🚨 **过度口语化**：把论文写成了报告/推文风格。

### 7.8 接口落位
- 润色为语言/质量工程，**无外部取数需求**。

### 7.9 回退逻辑
⇦ 润色中发现结构性/逻辑性问题 → 回退到 6（乃至 5）；仅文字性问题在本环节内解决。

---

## 环节 8：引用 / 参考文献校验

### 8.1 定义
对全文所有引用与文末参考文献做**真实性、准确性、一致性**核验。**这是最容易出学术不端与硬伤的一环。**

### 8.2 输入 / 输出
- 输入：正文引用点、参考文献列表。
- 输出：**已校验的引用/参考文献库**（题录准确、格式规范、引用与文末一一对应）。

### 8.3 核心验收标准
- ✅ 正文所有引用的条目都能在文末找到（**无双向缺漏**：无引而列、无列而引）。
- ✅ 每条文献题录真实准确（篇名/作者/刊名/年份/卷期页对得上，非编造）。
- ✅ 引用体例统一（GB/T 7714 或 IEEE 等，按学校/学科规范）。
- ✅ 标注形式正确（上标/著者-年份制等），图表引用已外联。
- ✅ 无"幽灵文献/伪引"（引了并不存在的文献——学术不端硬伤）。

### 8.4 常见分支场景
- **分支 A｜引用与文末不匹配** → 双向核对修正（这是最高频问题）。
- **分支 B｜题录信息错误/缺失**（年份、卷期不全） → 回查补全。
- **分支 C｜格式体例混用**（GB/T 7714 与 APA、IEEE 混用） → 全文统一。
- **分支 D｜被引文献不可回溯**（无原文可查） → 判断是"信息错误"还是"伪引"，伪引必须删除（红线）。

### 8.5 本硕博差异
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 文献数量 | 少 | 中 | 多而深 |
| 外文/国际文献 | 少 | 中 | **大量** |
| 引用体例规范要求 | 基本规范 | 严格 | **极严格** |
| 对引用准确性的容忍 | 低 | 中 | **零容忍** |

### 8.6 高频规范要求
- 遵循 GB/T 7714-2015（或学校/期刊指定体例）。常见要素：作者、题名、刊名、年、卷(期)、页码；电子文献含 DOI/URL 与访问日期。
- 作者超 3 人常"等"处理（体例差异酌情）。
- 学位论文中引用学位论文、专著、会议、报告需区分类别标识。
- 严禁编造、转引不核对、张冠李戴。

### 8.7 踩坑清单
> - 🚨 **伪引/幽灵文献**：最严重学术不端失分项。
> - 🚨 **转引不当**：借他人引文而不核原文，误读原意或错归作者。
> - 🚨 **张冠李戴**：把 A 的观点算到 B 头上。
> - 🚨 **体例混用/乱码**：中英文文献格式混乱、缺失卷期页。
> - 🚨 **引用与文末不同步**：三改两改后错位。

### 8.8 接口落位（可对接万方）
- 文献真实性核验可对接**万方文献库检索**按题录反查，确认篇名/作者/刊名/年份/卷期页是否存在且一致（这是"真实性"最直接的支撑）。

### 8.9 回退逻辑
⇦ 发现伪引 → 删除并回退到环节 3/4 找替代真实文献；题录错误 → 本环节内回查修正。

---

## 环节 9：格式排版

### 9.1 定义
将稿件按学校/学位要求的**版式规范**排版（字体、字号、行距、页边距、页眉页脚、图表、目录、页码、前后置件）。

### 9.2 输入 / 输出
- 输入：润色稿 + 学校格式模板/规范。
- 输出：**符合格式要求的"排版稿"**。

### 9.3 核心验收标准
- ✅ 前置件齐全且顺序正确：封面 → 原创声明 → 中文摘要 → 英文摘要 → 目录 → 正文 → 参考文献 → 附录 → 致谢/答辩材料（按学校要求）。
- ✅ 字体字号、行距、页边距、页眉页脚、页码全部符合模板。
- ✅ 目录自动生成且页码与正文一致；图表编号与引用一致、图表规范。
- ✅ 公式排版规范、编号连续；符号统一。
- ✅ 页面整洁、无悬挂标题、无孤行/孤字（排版细节）。

### 9.4 常见分支场景
- **分支 A｜模板权限/版本问题**（用错学校模板） → 回退使用正确模板。
- **分支 B｜目录/交叉引用更新后错位** → 需更新的域/引用全部刷新。
- **分支 C｜图表过多、排不下** → 调整分页/版面，保证"先文后图、图随文走"。

### 9.5 本硕博差异
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 前置件 | 相对简单 | 标准齐全 | **需更多（创新点声明/答辩材料等）** |
| 排版严格度 | 中 | 高 | **极高（常需盲审格式）** |
| 摘要/关键词要求 | 基本 | 规范 | **严格（中英文摘要质量高、关键词准确）** |
| 页数/篇幅 | 少 | 中 | 大 |

### 9.6 高频规范要求
- 摘要：中文 + 英文；关键词 3~5 个、准确、符合学科规范。
- 原创性声明、版权页、致谢按学校要求。
- 参考文献排在正文后、按要求排序；附录非必需。
- （理工）公式用排版系统规范书写，符号/单位统一。

### 9.7 踩坑清单
> - 🚨 **目录页码与实际不符**（未更新域）。
> - 🚨 **摘要/关键词不规范**：摘要写成"目录"式、关键词不规范。
> - 🚨 **封面信息错漏**（题目与正文不一致）。
> - 🚨 **图表编号/引用错乱**、图注表注不规范。
> - 🚨 **前后置件顺序/内容错误**（尤其盲审格式要求）。

### 9.8 接口落位
- 排版为版式工程，**无外部取数需求**。

### 9.9 回退逻辑
⇦ 一般在本环节内反复对齐模板即可；若发现内容层面的问题（如摘要与正文不符、图表缺来源）→ 回退到对应环节（6/8）修正。

---

## 环节 10：最终定稿

### 10.1 定义
全稿的最终一致性、完整性、合规性检查，确认达到送审/答辩标准，并归档可提交版本。

### 10.2 输入 / 输出
- 输入：已排版稿 + 全套检查项。
- 输出：**最终稿**（通过全部检查，可提交），附提交清单说明。

### 10.3 核心验收标准
- ✅ 全流程 10 环验收项**全部通过**（选题清晰、新颖度达标、文献充分、综述批判、大纲闭环、论证可靠、润色到位、引用准确无伪引、排版规范）。
- ✅ 查重结果满足学校阈值（未超限、引用已规范处理）。
- ✅ 关键材料齐备（承诺书、论文、附件、答辩PPT 等按需）。
- ✅ 全文一致性：题目/摘要/正文/结论表述一致，无信息矛盾。

### 10.4 常见分支场景
- **分支 A｜查重超限** → 定位重复段，改写/加引/压缩，**回退到 6/7/8** 处理。
- **分支 B｜评审/盲审意见存在** → 若为"修改后答辩"→ 回到相应环节修改；若为流程问题 → 补材料。
- **分支 C｜格式/材料不齐** → 补齐。

### 10.5 本硕博差异
| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| 查重要求 | 较低（阈值相对宽松） | 中 | **严格（阈值更低）** |
| 答辩/盲审深度 | 浅 | 中 | **深（盲审与外审）** |
| 提交材料复杂度 | 简单 | 标准 | **复杂（含创新点论证、外审）** |
| 是否强调原创性指控防御 | 弱 | 中 | **强（需自证原创边界）** |

### 10.6 高频规范要求
- 提交前做**查重**与**学位授予要求的逐项核对**（学校当年公布的细则）。
- 电子版/纸质版一致；承诺书、版权页齐全。
- 保留过程版本（便于审计与应对反馈）。

### 10.7 踩坑清单
> - 🚨 **提交前忘了查重**或引用处理不当导致超限。
> - 🚨 **材料不齐、版本错乱**（把草稿当天稿提交）。
> - 🚨 **题目/作者/学科等关键信息与注册信息不一致**。

### 10.8 接口落位
- 定稿侧重流程与合规核验，**无外部取数需求**。

### 10.9 回退逻辑
⇦ 定稿并非终点，是"最终验收门"，任何一项不过即回退到对应环节；务必保留可追溯的状态。

## 3. 本硕博差异总表（速查）

| 环节 | 本科（学士） | 硕士（学硕/专硕） | 博士 |
|---|---|---|---|
| 1 选题 | 限定小问题 | 真实问题、有边界 | 体系化、有纵深 |

| 3 调研 | 量少够用 | 主干+近年 | **穷尽主干+国际前沿** |
| 4 综述 | 介绍性 | 分析性 | **批判性、建构立场** |
| 5 大纲 | 模板化 | 结构化 | **可含独立成果章节** |

> **记忆口诀**：本科"规范完成一个限定问题"；硕士"方法+创新点解决真实问题"；博士"原创性贡献，且须回答前人为何没做到"。

## 4. 全局学术规范红线（勿踩）

1. **学术不端**：伪造数据/实验、抄袭、代写、伪引、一稿多投——一票否决。
2. **引用真实**：杜绝幽灵文献、张冠李戴、转引不核对。
3. **查重合规**：引用规范处理，重复率低于学校红线。
4. **伦理合规**：涉人体/动物实验需伦理批号；数据注明来源授权。
5. **平权表达**：全文及产物不得使用女性贞洁隐喻的词汇（"处女地/处女作"→"空白领域/开山之作"）。

## 5. 典型回退迭代环路（Agent 状态机关键）

```
选题(1) --新颖度不达标--> 换题/收敛(回1)
  ↑                            │
  │       新颖度达标          ↓
  └── 新颖度评估(2) <──综述冲突── 文献综述(4)
                                  │证据不足
                                  ↓
                            文献调研(3) <──补检索
                                  │
                                  ↓
                            大纲(5) ──逻辑断链──> 回5修订
                                  │
                                  ↓
                            撰写(6) ──证据不足/论证弱──> 回6/回5/回3
                                  │
                                  ↓
                            润色(7) ──结构与逻辑问题──> 回6
                                  │
                                  ↓
                            引用校验(8) ──伪引/题录错──> 回3/4 或 本环修正
                                  │
                                  ↓
                            排版(9) ──内容层问题──> 回6/8
                                  │
                                  ↓
                            定稿(10) ──查重超限/材料不齐──> 回对应环节
```

> **Agent 实现要点**：把"回退"建模为**带前驱指针的状态**，跨环回退要保留上下文（创新点、文献池、大纲）以免断层；每环验收用**布尔化看门**（通过/不通过 + 回退目标）。

## 6. Agent 化落地建议（供开发参考）

### 6.1 推荐分层
- **编排层（Orchestrator）**：运行 FSM，按学位等级路由阈值，维护全局上下文（题目/创新点/文献池/大纲/各章）。
- **环节执行层（Per-phase Agent）**：每个环节一个执行体，负责本环节的产出与自我验收。
- **合规校验层（Guardrail）**：独立检查学术规范红线（伪引、查重、伦理、平权表达），可在关键环节插桩。
- **数据支撑层（万方检索可选）**：新颖度评估、文献调研、文献真实性核验、综述趋势等环节，可对接万方数据官方接口取真实结果（见第 7 章）。

### 6.2 关键数据结构（建议字段）
- `topic`: { question, scope, degree, novelty, noveltyStatus }
- `literaturePool`: [{ id, title, authors, source, year, vol, issue, pages, category, summary, verified }]
- `outline`: { chapters: [{ id, title, objective, evidence, words, contribution }] }
- `chapterDraft`: { chapterId, status, sections, needsEvidence }
- `citationMap`: { inTextRefId → bibRefId, checked }
- `guardrailLog`: { issue, severity, action }

### 6.3 分环验收模板（直接当 Agent 的 prompt/评分器）
每个执行体返回四字段：
```
{ "output": "...", "accept": true/false, "fallbackTo": "<前置环节id>", "issues": ["..."], "evidence": ["..."] }
```

## 7. 可用数据接口支撑（万方选题，通俗命名）

> 以下为**可选接入**的真实数据源落地位，用于让"新颖度评估 / 文献调研 / 综述趋势 / 引用真实性"从"凭感觉"升级为"有据可依"。接口异常时如实回避，**不得编造替代结论**。

| 环节 | 可调用的万方能力（通俗说法） | 作用 |
|---|---|---|
| 1 选题 | 万方学术主题分布、万方交叉学科分布、万方关联主题词 | 定位问题所属主题、扩展关键词 |
| 2 新颖度评估 | 万方研究前沿脉络库、万方新兴主题库、万方选题评估 | 判断是否已成熟/空白、是否有空间 |
| 3 文献调研 | 万方文献库检索、万方学者库检索、万方期刊选题学科分类 | 取题录摘要、找主轴学者 |
| 4 文献综述 | 万方研究前沿脉络库、万方研究趋势报告、万方学者库检索 | 划阶段、看趋势、理主流阵营 |
| 8 引用校验 | 万方文献库检索（按题录反查） | 核验题录真实性与一致性 |

## 8. 结论（给 Agent 的一句话接入原则）

> 本硕博论文流程的 **10 环骨架是共用的**，区别在于：**① 每一环的验收阈值与深度**，**② 第 2/6 环节对"创新点/原创贡献"的硬性要求**，**③ 第 3/4 环节文献的广度与批判深度**。
> Agent 应建**一份 FSM + 学位等级路由参数**，而不是三套孤立流程；凡评估/调研/真实性核验类结论，必须接入真实数据源（万方），杜绝凭空编造。

## 数据说明与可信边界（通俗版）
- **关于"50"这个数字**：若对接万方文献检索时，接口最多只数到 50 篇就停。所以凡显示 50 的，代表"至少有 50 篇、具体多少不知道"，不能拿来比谁更热门；只有小于 50 的数字才是真实召回量。判断窍门：看"页数"，等于 5 页就是撞到上限，小于 5 页才是真值。
- **关于"没查到"**：分两种情况——一种是这个方向在库里还没沉淀成熟的研究脉络（对你选题反而是好信号，说明还不拥挤）；另一种是当时网络没连上、请求超时（数据其实有，只是没取回来），这类我们会注明"本次未纳入"。
- **关于"学科没名字"**：万方交叉学科分布只返回学科编号、不给可读名称，所以报告里只能说"存在若干相关学科、各自热度如何"，叫不出具体学科名，这不是漏查，是接口格式如此。
- **本文档的验收阈值/字数/文献量区间**属于行业通行质量标准与经验区间，**非**某一具体学科的真实查新结论；真实取数须在选题/调研/评估环节接入万方接口后确认。
